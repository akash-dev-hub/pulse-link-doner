# PulseLine - Blood Donor Finder

Problem Statement: SW-11 (HealthTech / Web Development)

## Problem
Families lose critical time finding blood donors through forwarded messages and calls.

## Features
- Donor registration and login
- Search donors by blood group and location
- Emergency request board with close option
- 90-day eligibility check
- Map view
- In-app notifications

## Tech Stack
Google AI Studio, React, Firebase Authentication, Cloud Firestore

## Privacy
Donors control their visibility.

## Future Scope
Compatible blood group matching, SMS/email alerts
